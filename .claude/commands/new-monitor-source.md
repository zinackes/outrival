Ajoute une nouvelle source de monitoring à Outrival de bout en bout.

Invoque le skill `outrival-new-source`.

Demande d'abord :
1. Nom de la source (ex: linkedin, twitter, appstore)
2. Type de capture : `scrapeStatic` (L0 fetch) ou `scrapePage` (rendu navigateur) ou API/feed
3. Fréquence recommandée : realtime / daily / weekly
4. URL d'exemple pour tester

Puis suis la checklist complète du skill dans l'ordre exact.
