## Findings considered and rejected (so they aren't re-audited)

- **Transitive `undici`/`ws`/`systeminformation` high advisories** — real advisories, but
  the security pass judged them **not on reachable exploit paths** (undici via cheerio
  parsing not fetching; ws/systeminformation via Trigger host-metrics with no user input).
  Not worth a plan now; revisit if a deeper reachability audit changes the verdict. (Only the
  **direct** hono CORS advisory is planned — 008.)
- **`next-mdx-remote@5` RCE advisory** — real, but MDX is repo-authored (read from disk), so
  not attacker-reachable today. Noted as a low-urgency bump in plan 008's Maintenance, not a
  standalone plan.
- **JSON-LD `dangerouslySetInnerHTML` escaping** — the data feeding the three JSON-LD sinks is
  static/repo-authored today (not attacker-reachable). Defense-in-depth only; fold the escape
  into any future change that wires dynamic/scraped/AI content into those components.
- **`signal-batching` non-transacted insert+update** and **digest send-before-stamp double
  email** — real but narrow (require a mid-loop crash in a small window); lower leverage than
  the planned set. Worth a small transaction/idempotency-key follow-up if they ever recur.
- **ai-visibility missing `AT TIME ZONE 'UTC'`** — real convention violation, low visible
  magnitude (only the "checked <date>" line / day bucketing for cross-day-boundary viewers).
  Fold into any future edit of `ai-visibility.ts`.
- **`lib/api.ts` god-module (2,976 lines, fan-in 116)** and **finishing the TanStack Query
  migration (17 self-fetchers)** — real, high-value tech-debt, but **L effort** decomposition
  work better scheduled as a deliberate refactor project than an advisor handoff plan. Not
  rejected on merit — deferred by size. Same for the other >1000-line god files
  (`competitor-detail-view.tsx`, `competitors.ts`, `scrape-monitor.job.ts`) and the shadcn
  primitive normalization (signals-view hand-rolled sheet).
- **No linter/formatter (Biome)** — worth doing (M effort + an initial cleanup pass), but a
  formatting sweep is best run interactively by the operator (ratchet from non-blocking) than
  as an executor plan; add it as a CI step once 006 lands.
- **`.env.example` drift, agent-hook 127KB injection, root README, radix/turbo pinning,
  notification-insert dedup** — genuine DX/debt nits, individually below the planning
